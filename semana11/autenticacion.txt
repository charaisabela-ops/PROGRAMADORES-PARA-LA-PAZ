El login es el mecanismo que permite a un usuario acceder al sistema mediante el ingreso de sus credenciales, como el nombre de usuario o correo electrónico y su contraseña. Una vez ingresadas, la aplicación verifica que la información sea correcta y, si la autenticación es exitosa, concede acceso a las funciones y recursos autorizados para ese usuario.
Es importante proteger algunas rutas o secciones de la aplicación porque no todos los usuarios deben tener los mismos permisos. Por ejemplo, un coordinador puede tener la capacidad de revisar, actualizar o administrar los reportes registrados, mientras que un ciudadano únicamente debería poder crear incidencias y consultar las que le corresponden. Esta restricción ayuda a garantizar la seguridad de la información y evita accesos o modificaciones no autorizadas.
Asimismo, existen datos que nunca deben exponerse públicamente, ya que podrían comprometer la seguridad de los usuarios y del sistema. Entre ellos se encuentran las contraseñas, los tokens de autenticación, las claves de API y la información personal sensible, como números de documento, direcciones y teléfonos. Proteger estos datos es fundamental para preservar la privacidad de los usuarios y prevenir posibles riesgos de seguridad.
